# Allyoop 🏀

[![js-standard-style](https://img.shields.io/badge/code%20style-standard-brightgreen.svg?style=flat)](https://github.com/feross/standard)

A cross-platform React Native application for tracking NBA live scores, player statistics, detailed game box scores, and team standings.

![group](https://cloud.githubusercontent.com/assets/5305874/12059257/dacf1ad0-af92-11e5-920c-ba4818d8dc1d.png)

## 📌 Project Overview

- **Maintainer:** Utkarsh Verma
- **Platform:** iOS & Android
- **State Management:** Redux + Redux-Thunk
- **Code Style:** Standard
- **Repository:** [UtkarshV26/Allyoop](https://github.com/UtkarshV26/Allyoop)

## 🚀 Development Setup

### Prerequisites

Before running the project, make sure you have:

- Node.js
- npm
- React Native CLI
- Android Studio & Android SDK for Android development
- Xcode for iOS development
- A configured Android emulator or physical Android device
