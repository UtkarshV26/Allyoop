## 🚀 Development Setup

### Prerequisites
- Node.js & npm
- React Native CLI
- Xcode (for iOS) / Android Studio & SDK (for Android)

### Installation
```bash
git clone https://github.com/ayush37821/Allyoop-react-native-nba-app.git
cd Allyoop-react-native-nba-app
npm install
```

#### Running on iOS
1. `npm run clean`
2. `npm start`
3. Open Xcode, select a simulator, and run (`Cmd + R`).

#### Running on Android
1. Start the packager: `npm start`
2. Run the Android app: `react-native run-android`
